APA Paper Formatter

Fill in the title page, paste your paper as plain text, and download a Word document set up to APA 7 student-paper standards: Times New Roman 12, double spacing, one-inch margins, page numbers, headings, and a hanging-indent reference list.

Headings: start a line with # for a main section, ## for a subsection, ### for a sub-subsection. A line that says only Abstract or References starts that section automatically. Begin a long quotation with > to set it as a block quote.

Preview shows the title page and the first page of text. The Word file contains the whole paper.
